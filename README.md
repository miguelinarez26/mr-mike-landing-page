# Mr. Mike Burger & Hot Dogs Landing Page

This repository contains the source code for the Mr. Mike Burger & Hot Dogs landing page.

## Project Structure

- `index.html`: The main entry point of the application, containing the single-page application structure using React and Tailwind CSS via CDN.

## Technologies Used

-   **HTML5**
-   **React** (via CDN)
-   **React Router** (via CDN)
-   **Tailwind CSS** (via CDN)
-   **Google Fonts** & **Material Icons**

## Getting Started

Simply open `index.html` in any modern web browser to view the application.
